# Studio Garage — media

Published-artwork mirror. Buffer fetches Instagram carousel slides by public URL, so the
images must be reachable without authentication at publish time.

This repository holds **only rendered slides**. It deliberately contains no strategy, no
unpublished copy, no briefs, and no operating documents — those live in the private
Studio Garage OS repository.

Source of truth is that private repo. Files here are build output; do not edit them.
